# PHANTOM WARRIOR website

Static site: HTML5, CSS3, vanilla JavaScript only. No build step.

## Open it
Unzip, then open `index.html` in a browser.

## Structure
- 7 pages in the root: index, about, teams, maps, plan-maps, contact, login
- `assets/css/` style (tokens, base), components, responsive
- `assets/js/` config (name, social links), navigation (menu), main (reveals, footer, sparks)
- `docs/` roadmap, asset guide, next-batch brief

## Images
The site uses one logo: `assets/images/logo/pw-primary-logo.png` (square). See `docs/ASSET_GUIDE.md`.
